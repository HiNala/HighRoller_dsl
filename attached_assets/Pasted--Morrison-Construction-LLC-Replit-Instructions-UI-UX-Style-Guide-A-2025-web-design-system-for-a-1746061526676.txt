✅ Morrison Construction LLC — Replit Instructions & UI/UX Style Guide
A 2025 web design system for a standout Idaho-based construction company.

🧠 REPLIT AGENT INSTRUCTIONS (INITIAL SETUP)
1. Create the Next.js 15 Project with TypeScript
bash
Copy
Edit
npx create-next-app@latest morrison-construction --app --ts --tailwind
cd morrison-construction
✅ Use App Router and enable src/ directory during setup.

2. Install UI Libraries
bash
Copy
Edit
npm install framer-motion lucide-react clsx
Install shadcn/ui:

bash
Copy
Edit
npx shadcn-ui@latest init
npx shadcn-ui@latest add button card input navigation-menu
3. Configure Tailwind Theme in tailwind.config.ts
ts
Copy
Edit
import type { Config } from "tailwindcss";

const config: Config = {
  content: [
    "./src/**/*.{ts,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        primary: '#3C3C3C',    // Charcoal Gray
        accent: '#D88F2C',     // Earthy Amber
        neutral: '#F5F5F5',    // Bone White
        dark: '#1F1F1F',
        light: '#FFFFFF',
        border: '#E5E7EB',
      },
      fontFamily: {
        sans: ['Inter', 'sans-serif'],
        display: ['Playfair Display', 'serif'],
      },
      borderRadius: {
        xl: '1rem',
        '2xl': '1.5rem',
      },
    },
  },
  plugins: [],
};
export default config;
4. Set Global Fonts in app/layout.tsx
tsx
Copy
Edit
import "./globals.css";
import { Inter, Playfair_Display } from "next/font/google";

const inter = Inter({ subsets: ["latin"], variable: "--font-sans" });
const playfair = Playfair_Display({ subsets: ["latin"], variable: "--font-display" });

export const metadata = {
  title: "Morrison Construction LLC",
  description: "Building Boise Better – Residential & Commercial Excellence",
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={`${inter.variable} ${playfair.variable}`}>
      <body className="bg-neutral text-primary">{children}</body>
    </html>
  );
}

📈 SEO & PERFORMANCE
Use <Image> component from next/image

Add meta tags in app/layout.tsx and next-seo.config.js (optional)

Lazy load components and images

Use semantic HTML (e.g., <section>, <article>, <header>)

🧑‍🎨 DESIGN NOTES
Keep layout wide but not full-screen (max-w-screen-xl mx-auto)

Emphasize Idaho craftsmanship and regional pride

Icons: use Lucide (import { Hammer } from "lucide-react")

Use lots of white space for breathing room

No overwhelming animations — calm, clean, and professional
