# Morrison Construction LLC Website

A modern, responsive construction company website for Morrison Construction LLC, a residential remodeling company based in Boise, Idaho.

## Overview

This project is a professional business website for Morrison Construction LLC, featuring a modern design optimized for desktop and mobile viewing. The site showcases the company's residential remodeling services, including kitchen and bathroom remodels, home additions, and outdoor living spaces.

## Features

- **Responsive Design**: Mobile-first approach ensuring the website looks great on all devices
- **Modern UI**: Clean, professional aesthetic with an intuitive user interface
- **Interactive Elements**: Smooth animations and transitions powered by Framer Motion
- **Service Showcase**: Detailed sections highlighting the company's specialized services
- **Project Portfolio**: Gallery of featured projects with filtering capabilities
- **Testimonials**: Carousel of client testimonials to build trust
- **Contact Form**: Easy-to-use form for potential clients to reach out
- **Google Maps Integration**: Interactive map showing the company's location

## Technology Stack

- **Frontend Framework**: React with TypeScript
- **Styling**: Tailwind CSS for utility-first styling
- **UI Components**: Shadcn UI component library
- **Animation**: Framer Motion for smooth transitions and animations
- **Routing**: Wouter for lightweight page routing
- **Code Quality**: ESLint and TypeScript for type safety
- **Development Server**: Vite for fast development experience

## Design

The design follows a clean, professional aesthetic with a color palette that includes:

- Primary Color: Charcoal Gray (#3C3C3C)
- Secondary Color: Bone White (#F5F5F5)
- Accent Color: Earthy Amber (#D88F2C)

Custom utility classes have been implemented to maintain consistent styling throughout the application.

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5000`
